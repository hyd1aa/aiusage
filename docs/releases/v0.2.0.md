# AIUsage v0.2.0

One command for beginners:

```bash
ai
```

Direct dashboard for experienced users:

```bash
aiusage
```

The management menu provides:

- Launch dashboard
- Demo mode
- Shared settings
- Safe stable-release update checks
- Read-only diagnostics
- Confirmed uninstall

If another program already owns the short `ai` command, AIUsage will never
overwrite it. The stable management entry always remains available:

```bash
aiusage --menu
```

This release also includes configurable display timezones, the `Z` timezone
selector, fixed UTC offsets, live system-timezone following, correct date
rollover, compact numeric UTC labels, and DST-aware system conversion.

AIUsage remains an unofficial community utility.
