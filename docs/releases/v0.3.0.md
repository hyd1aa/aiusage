# AIUsage v0.3.0

The published AIUsage runtime is now Rust. This is a structural runtime and
distribution change, not a Dashboard redesign.

User configuration stays compatible. CODEX and GROK provider behavior, the
Dashboard, management menu, timezone conversion, discovery, and refresh
cadence remain compatible with the Python 0.2.2 reference.

Python 3.10 is the canonical behavior oracle. This release does not claim
bit-for-bit identity with every Python version. Recorded non-blocking
differences remain:

- Arbitrary legacy-codepage transcoding is out of scope.
- Rust integers are bounded; Python bigints are not.
- Invalid Codex reset objects are not rendered as arbitrary Python objects.

The Python source remains in the repository as the differential reference and
as the rollback implementation. A previously rehearsed path is:

Python 0.2.2 → Rust → Python 0.2.2

Configuration checksums were unchanged in that drill.

## Supported binaries

- Linux amd64: stripped musl static binary
- Linux arm64: stripped musl static binary
- macOS arm64: self-contained application binary linking the OS-provided
  libSystem, libiconv, and CoreFoundation (not claimed fully static)

Asset names:

```text
aiusage-v0.3.0-linux-amd64
aiusage-v0.3.0-linux-arm64
aiusage-v0.3.0-macos-arm64
```

The updater installs only these official GitHub Release binaries after origin,
SHA-256 digest, and `aiusage --version` checks. It does not fall back to
installing a Python source archive over a Rust binary.

Replacing a running Python production installation is not part of this
release. Keep the matching Python 0.2.2 source if you need to roll back later.
