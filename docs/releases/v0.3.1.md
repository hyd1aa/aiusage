# AIUsage v0.3.1

Rust-only maintenance and cleanup release. This is not a new feature
release and does not change the Dashboard, provider readers, or user
configuration format.

v0.3.0 installs can upgrade directly. User configuration is left untouched.

## What changed

- The legacy Python runtime, launchers, packaging, rollback runtime, and
  Python CI are removed. The repository is Rust-only.
- `rust/Cargo.toml` package metadata is the only version source for the
  runtime, diagnostics, updater, installer checks, CI, and release builds.
- Frozen golden fixtures stay in the tree as the compatibility protection
  for CLI, menu, CODEX, GROK, timestamp, timezone, and Dashboard behavior.
- The repository-root installer installs only a verified Rust binary.
  Ownership checks and the atomic publish path were hardened.
- PTY tests use a portable terminal size so the same cleanup checks run on
  macOS and Linux.
- CI and release packaging are Rust-only.

## Supported binaries

Platform support is unchanged:

- Linux amd64: stripped musl static binary
- Linux arm64: stripped musl static binary
- macOS arm64: self-contained application binary linking the OS-provided
  libSystem, libiconv, and CoreFoundation (not claimed fully static)

Asset names:

```text
aiusage-v0.3.1-linux-amd64
aiusage-v0.3.1-linux-arm64
aiusage-v0.3.1-macos-arm64
```

The updater installs only these official GitHub Release binaries after origin,
SHA-256 digest, and `aiusage --version` checks.
