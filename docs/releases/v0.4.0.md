# AIUsage v0.4.0

AIUsage v0.4.0 introduces the one-line static binary installer, automated GitHub
Actions release workflows, and Gemini CLI (`gemini_cli`) provider support.

## What changed

- **One-line installer**: Added `scripts/install.sh` to download precompiled static
  musl binaries with architecture auto-detection (x86_64, aarch64, macOS).
- **Automated CI/CD**: Added `.github/workflows/release.yml` to compile and publish
  static release assets for Linux x86_64 and aarch64 on GitHub Release tags.
- **Gemini CLI Support**: Added `gemini_cli` provider with automatic detection of
  `agy` / `gemini` commands and local OAuth tokens (`~/.gemini/antigravity-cli/antigravity-oauth-token`).
- **Quota & Token Parsing**: Safely extracts quota window percentages and handles
  unlimited developer tiers honestly without fabricating estimates.
- **Provider Manager**: Fully integrated Gemini CLI into auto-discovery, interactive
  menu (`--menu`), diagnostics, and isolated demo mode.

## Supported binaries

- Linux amd64: stripped musl static binary (`aiusage-v0.4.0-linux-amd64`)
- Linux arm64: stripped musl static binary (`aiusage-v0.4.0-linux-arm64`)
- macOS arm64: self-contained application binary (`aiusage-v0.4.0-macos-arm64`)
