# AIUsage v0.4.1

AIUsage v0.4.1 enhances Gemini CLI (Google Code Assist) quota parsing to extract
and display 5-hour and 7-day (Week) quota windows with real progress bars and reset times.

## What changed

- **Gemini CLI Quota Windows**: Parses Google Code Assist `retrieveUserQuotaSummary`
  responses (`groups`, `buckets`, `quotaInfo`), correctly extracting 5h (`18000s`) and Week (`604800s`) windows.
- **Quota Progress & Reset Time**: Renders remaining quota percentages, progress bars, and localized reset timestamps matching the Codex layout.
- **Request Headers & Fallback**: Added `User-Agent: antigravity/1.3.3` header to prevent 403 Forbidden errors from Google Code Assist API endpoints.
- **Test Coverage**: Added test fixtures and golden compatibility tests for 0.4.1.

## Supported binaries

- Linux amd64: stripped musl static binary (`aiusage-v0.4.1-linux-amd64`)
- Linux arm64: stripped musl static binary (`aiusage-v0.4.1-linux-arm64`)
- macOS arm64: self-contained application binary (`aiusage-v0.4.1-macos-arm64`)
